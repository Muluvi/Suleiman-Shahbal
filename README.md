# Suleiman Shahbal Mombasa 2027 — Digital Campaign Strategy Proposal

An independent, evidence-grounded digital campaign strategy proposal for **Hon. Suleiman Shahbal's** Mombasa County gubernatorial campaign in the August 2027 Kenyan General Election.

Prepared by **Firefly Management** (Nairobi & Mombasa, Kenya).

---

## Strategic Objective

To maximise supporters and registered voters through persuasion and mobilisation—specifically transforming Mombasa's 424,000 non-voters (who abstained during the 34.1% turnout election of 2022) and emerging Gen-Z registrants into a decisive, high-turnout coalition behind proven economic stewardship.

---

## Strategy Modules

1. **Executive Summary & 2-Minute Candidate Brief**: Mathematical pathway to victory, voter turnout calculus, and 5 immediate strategic imperatives.
2. **Voter Persuasion & Mobilisation Strategy**: Segment-by-segment conversion funnels (Awareness → Registration → Persuasion → GOTV) across 8 demographic groups.
3. **Issue & Narrative Framework (Message House)**: Roof narrative, 4 core economic pillars, verified proof points, audience variants, and message do's and don'ts.
4. **Social Media & 12-Week Content Calendar**: Multi-platform matrix (WhatsApp Channels, TikTok, Facebook, X, Instagram, YouTube), Swahili campaign slogans & hashtags, creator tiering, and an interactive 12-week pre-campaign sprint calendar.
5. **Data, Analytics & 30-Ward Targeting Framework**: Ward-level database of all 30 wards across the 6 sub-counties (Kisauni, Nyali, Mvita, Likoni, Changamwe, Jomvu) with official 2022 IEBC registration figures and local priorities, strictly compliant with Kenya's Data Protection Act, 2019.
6. **Rapid Response & Misinformation Management**: 5-level escalation ladder, 60-minute fact-check SLA workflow, spokesperson authorization rules, and coastal crisis playbook.
7. **Rivals: Issue-Based Contrast Only**: Verifiable public comparisons on governance record, fiscal execution, and delivery with Abdulswamad Shariff Nassir and Hassan Omar.
8. **Verification Checklist & Sources Directory**: Action items marked `[VERIFY]` for campaign confirmation, labeled placeholders, and verified primary citations (IEBC, KNBS, Controller of Budget, EALA, Public Records).

## Visual Design & Information Architecture

Built strictly in accordance with Firefly Management's reference handbook (*The Ultimate Guide to Website Visuals*, September 2026):

1. **Reading Progress Indicator** (Guide §2.4 & §7.2): Fixed top viewport progress bar showing document completion.
2. **Explanatory Arithmetic: Waterfall Build-Up** (Guide §4.9 & §5.8): Interactive multiplier formula (`Registered Electorate × Turnout Rate × Winning Vote Share = Victory Target`) with live sliders and data table toggle.
3. **Part-to-Whole 10×10 Waffle Grid** (Guide §4.7): 100-tile visualization proving that 66% (424,000+) of Mombasa voters abstained in 2022.
4. **Spatial Geographic Sub-County Map** (Guide §4.8 & §12.2): Interactive SVG regional map of Mombasa Island, Kisauni, Nyali, Likoni, Changamwe, and Jomvu with waterway channels, tap-friendly controls, and an accessible table fallback.
5. **Strategic 2×2 Positioning Quadrant** (Guide §5.6): Plotting Electorate Density vs Turnout Upside to identify high-yield mobilization zones.
6. **Interactive Crisis Decision Tree & Flowchart** (Guide §5.1 & §5.2): Branching emergency response pathways for AI deepfakes, forged withdrawal letters, and land rumors with strict SLA timers and Mermaid diagram fallback.
7. **Interactive Trader Single Permit Savings Calculator** (Guide §6.3): Personalised savings calculator for Kongowea wholesale traders and mama mbogas contrasting overlapping daily fees against a flat digital license.
8. **Shareable WhatsApp & Social Preview Card Generator** (Guide §6.5 & §12.1): Real-time renderer for 1:1 and 16:9 share cards with one-click WhatsApp text formatting and direct sharing.
9. **Accessibility & Kenya Low-Bandwidth Standards** (Guide §10, §11 & §12): WCAG AA contrast, `prefers-reduced-motion` compliance, visible keyboard focus rings, touch targets ≥ 44px, and "View as Data Table" toggles on all graphics.

## Technology Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Motion**: Motion (Framer Motion v12)
- **Deployment**: Zero-backend, fully offline static site compatible with Vercel, Cloud Run, Netlify, or GitHub Pages.

---

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# The site will be available at http://localhost:3000
```

---

## Building & Deploying to Vercel

```bash
# 1. Build the production bundle
npm run build

# 2. Preview locally
npm run preview

# 3. Deploy to Vercel via CLI
npx vercel
```

Alternatively, push this repository to GitHub and import it directly into your Vercel dashboard with standard Vite defaults (`dist` output directory).

## Research Grounding & Data Safeguards

- **Primary Sources**: Official IEBC 2022 gazetted voter register, 2019 KNBS Census, Office of the Controller of Budget FY23/24 reports, County Government of Mombasa CIDP 2023-2027.
- **Data Protection**: Strict adherence to Kenya's **Data Protection Act, 2019** (Sections 26 & 31); no harvesting or profiling of individual voters' private personal data.
- **National Cohesion**: Compliant with Kenya's **National Cohesion and Integration Act** and **Elections Act, 2011**; zero ethnic, religious, or personal attacks.
